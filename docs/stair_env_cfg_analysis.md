## 📋 配置文件概述

该配置文件定义了 Unitree G1 人形机器人上楼梯任务的完整强化学习环境配置，包含两种训练模式：
1. **盲爬模式 (StairBlindEnvCfg)**：仅依赖本体感知，不使用地形传感器
2. **带传感器模式 (StairClimbEnvCfg)**：使用高度扫描器感知前方楼梯地形

---

## 1. 楼梯地形配置 (STAIR_TERRAIN_CFG)

### 配置详情

| 参数 | 值 | 说明 |
|------|-----|------|
| 地形块尺寸 | 8.0m × 8.0m | 每个地形块的大小 |
| 难度等级 | 10行 × 20列 | 200种地形变体 |
| 水平分辨率 | 0.1m | 高度图采样间隔 |
| 垂直分辨率 | 0.005m | 高度值缩放因子 |

### 地形比例分配

| 地形类型 | 比例 | 阶高范围 | 踏面宽度 |
|----------|------|----------|----------|
| 平地 (flat) | 15% | - | - |
| 简单上楼梯 (stairs_up_easy) | 30% | 8-12cm | 35cm |
| 中等上楼梯 (stairs_up_medium) | 25% | 12-18cm | 30cm |
| 困难上楼梯 (stairs_up_hard) | 15% | 16-20cm | 28cm |
| 下楼梯 (stairs_down) | 15% | 10-15cm | 32cm |

### ✅ 优点

1. **合理的难度梯度**：从简单（8-12cm阶高）到困难（16-20cm阶高）的渐进设计符合课程学习原则
2. **使用 InvertedPyramid 地形**：机器人从边缘向中心攀爬，符合"上楼梯"的物理逻辑
3. **包含下楼梯训练**：15%的下楼梯地形有助于学习双向能力
4. **保留平地**：15%平地用于基础平衡学习，防止遗忘

### ⚠️ 潜在问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 困难阶高过大 | 中 | 16-20cm 阶高对于 G1 机器人可能过于激进 |
| 踏面宽度递减过快 | 中 | 困难级别的 28cm 踏面可能不足以稳定落脚 |
| 缺少斜坡地形 | 低 | 实际楼梯环境常有斜坡过渡 |

### 💡 改进建议

```python

    proportion=0.10,
    grid_width=0.1,
```

## 6. 奖励配置分析

### 奖励权重对比

| 奖励项 | 盲爬模式 | 带传感器模式 | 说明 |
|--------|----------|--------------|------|
| track_lin_vel_xy | 1.0 | 1.0 | 线速度跟踪 |
| track_ang_vel_z | 0.5 | 0.5 | 角速度跟踪 |
| alive | 0.15 | 0.15 | 存活奖励 |
| **upward_progress** | **1.5** | **1.5** | **楼梯核心奖励** |
| base_linear_velocity (z) | -1.0 | -1.0 | Z轴速度惩罚 |
| flat_orientation_l2 | -3.0 | -3.0 | 姿态惩罚 |
| base_height_l2 | -3.0 | - | 固定高度惩罚 |
| base_height_relative | - | -5.0 | 相对高度惩罚 |
| feet_clearance | 1.2 | 1.2 | 抬腿高度奖励 |
| gait | 0.5 | 0.5 | 步态奖励 |

### ✅ 优点

1. **向上进展奖励**：`upward_progress` (weight=1.5) 是楼梯任务的核心奖励
2. **抬腿高度增加**：`target_height=0.15m` 比平地的 0.1m 更高
3. **步态周期合理**：0.8s 的步态周期适合稳定攀爬
4. **带传感器模式使用自适应高度**：`base_height_adaptive` 解决了楼梯高度变化问题

### ⚠️ 潜在问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 盲爬模式高度惩罚冲突 | 高 | 固定目标高度 0.78m 在楼梯上会产生错误惩罚 |
| Z轴线速度惩罚过强 | 中 | 上楼梯时 Z 轴速度自然增加，-1.0 权重可能过严 |
| 缺少楼梯专用奖励 | 中 | 建议添加 `stair_forward_progress` |

### 💡 改进建议

```python
# 盲爬模式：降低高度惩罚权重或使用更宽松的目标
base_height_l2 = RewTerm(
    func=mdp.base_height_l2,
    weight=-1.5,  # 从 -3.0 降低到 -1.5
    params={"target_height": 0.78},
)

# 降低 Z 轴速度惩罚
base_linear_velocity = RewTerm(func=mdp.lin_vel_z_l2, weight=-0.5)  # 从 -1.0 降低

# 添加楼梯前进奖励
stair_forward = RewTerm(
    func=mdp.stair_forward_progress,
    weight=0.5,
    params={"stair_direction": [1.0, 0.0]},
)
```

## 🔧 优先改进建议

### 高优先级

1. **修复盲爬模式高度惩罚**
   - 问题：固定目标高度在楼梯上产生错误惩罚
   - 方案：降低权重或使用更宽松的高度范围

2. **添加后退速度命令**
   - 问题：无法学习后退下楼
   - 方案：将 `lin_vel_x` 范围改为 `(-0.2, 0.6)`

### 中优先级

3. **降低 Z 轴速度惩罚**
   - 问题：上楼梯时 Z 轴速度自然增加
   - 方案：将权重从 -1.0 降低到 -0.5

4. **添加脚部接触状态观测**
   - 问题：策略缺少脚部接触信息
   - 方案：添加 `feet_contact` 观测项

### 低优先级

5. **添加斜坡地形**
6. **添加楼梯专用课程学习**
7. **开启小幅外力干扰**

## 📝 结论

该配置文件整体设计合理，体现了对楼梯攀爬任务的深入理解。主要亮点包括：

1. **分阶段训练设计**：盲爬模式和带传感器模式的分离设计
2. **合理的难度梯度**：从简单到困难的楼梯配置
3. **楼梯专用奖励**：`upward_progress` 奖励函数设计合理
4. **适度的域随机化**：降低了推力干扰，适合楼梯环境

主要需要改进的是盲爬模式的高度惩罚问题和命令配置中缺少后退能力的问题。建议在实际训练前进行这些修改，以获得更好的训练效果。
