# 自适应参数修改实施报告

## 1. 概述

本报告记录了为 Unitree G1 机器人盲爬楼梯任务实施自适应训练参数调整系统的所有修改。该系统旨在根据训练进度自动调整环境参数、课程学习策略和 PPO 算法超参数，以提高训练效率和最终性能。

**主要目标：**
1. **分阶段训练**：自动识别训练阶段（从初始探索到精通楼梯）。
2. **动态参数调整**：根据阶段调整奖励权重、终止条件和 PPO 参数。
3. **自适应课程**：根据阶段切换地形难度课程学习策略。

---

## 2. 实施架构

系统由三个核心组件组成：

1.  **自适应状态管理器 (`adaptive_curriculum.py`)**：
    *   作为环境层的一部分运行。
    *   负责收集训练指标（Episode 长度、地形等级）。
    *   检测训练阶段并在阶段切换时更新环境参数（奖励、终止条件）。
    *   提供统一的课程学习函数入口。

2.  **自定义训练脚本 (`train_adaptive.py`)**：
    *   作为训练层的主循环运行。
    *   定期查询当前阶段。
    *   根据阶段更新 PPO 算法参数（学习率、熵系数等）。

3.  **配置集成 (`stair_single_blind_cfg.py`)**：
    *   将自适应课程函数注册到环境配置中。

---

## 3. 详细参数配置表

### 3.1 训练阶段定义

| 阶段 ID | 阶段名称 | 触发条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **Stage 0** | 初始探索期 | `mean_length < 100` | 机器人尝试站立，快速失败 |
| **Stage 1** | 站立稳定期 | `100 ≤ mean_length < 300` | 机器人学会站立，开始尝试移动 |
| **Stage 2** | 行走学习期 | `300 ≤ mean_length < 600` | 机器人学会平地行走，偶尔触发楼梯 |
| **Stage 3** | 楼梯适应期 | `mean_length ≥ 600` 且 `terrain < 3` | 机器人稳定行走，开始攻克低难度楼梯 |
| **Stage 4** | 楼梯精通期 | `mean_length ≥ 600` 且 `terrain ≥ 3` | 机器人熟练攀爬高难度楼梯 |

### 3.2 动态参数调整表

每个阶段的参数配置如下：

| 参数类别 | 参数项 | Stage 0<br>(探索) | Stage 1<br>(站立) | Stage 2<br>(行走) | Stage 3<br>(适应) | Stage 4<br>(精通) | 调整逻辑说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **奖励权重** | `alive` | **6.0** | 5.0 | 4.0 | 3.0 | 2.0 | 初期强生存激励，后期逐渐降低以关注任务目标 |
| | `upward_progress` | 0.5 | 1.0 | 2.0 | 3.5 | **5.0** | 逐步增加任务奖励权重，引导完成攀爬 |
| | `flat_orientation` | -1.0 | -1.5 | -2.0 | -1.5 | -1.5 | 中期严格约束姿态，后期适当放宽以适应攀爬动作 |
| | `action_rate` | -0.02 | -0.03 | -0.04 | -0.04 | -0.04 | 逐步增加动作平滑度约束 |
| **终止条件** | `limit_angle` | **1.4 (80°)** | 1.3 (74°) | 1.2 (69°) | 1.1 (63°) | **1.0 (57°)** | 初期宽松防早停，后期严格要求姿态 |
| **PPO 参数** | `learning_rate` | **1e-3** | 8e-4 | 5e-4 | 3e-4 | **1e-4** | 随训练深入降低学习率，实现精细微调 |
| | `entropy_coef` | **0.02** | 0.015 | 0.01 | 0.008 | **0.005** | 初期高熵鼓励探索，后期低熵利用策略 |
| | `clip_param` | 0.2 | 0.2 | 0.18 | 0.15 | 0.12 | 后期收窄更新幅度，防止策略崩溃 |
| | `desired_kl` | 0.015 | 0.012 | 0.01 | 0.008 | 0.005 | 配合学习率调整，收紧 KL 约束 |
| **课程策略** | 策略类型 | **Survival** | Survival | **Climb** | Climb | Climb | 初期基于存活时间升级，后期基于攀爬进度升级 |

## 4. 文件修改记录

### 4.1 新增文件

**`unitree_rl_lab/tasks/locomotion/mdp/adaptive_curriculum.py`**
*   **功能**：实现了自适应逻辑的核心。
*   **关键类/函数**：
    *   `AdaptiveState` (Singleton): 存储滑动平均指标和当前阶段。
    *   `STAGE_CONFIGS` (Dict): 定义所有阶段的参数配置。
    *   `_detect_stage()`: 阶段判断逻辑。
    *   `_update_reward_weights()`: 动态修改奖励权重。
    *   `_update_termination_params()`: 动态修改终止阈值。
    *   `adaptive_terrain_levels()`: 主入口，集成阶段检测和课程分派。
    *   `update_ppo_params()`: 用于外部脚本更新 PPO 参数。

**`unitree_rl_lab/scripts/rsl_rl/train_adaptive.py`**
*   **功能**：替代标准 `train.py` 的增强版训练脚本。
*   **关键修改**：
    *   导入了 `adaptive_curriculum` 模块。
    *   实现了 `adaptive_learn` 循环。
    *   每 `ppo_update_interval` 步检查阶段变化并更新 runner 中的算法参数。

### 4.2 修改文件

**`unitree_rl_lab/tasks/locomotion/mdp/__init__.py`**
*   **修改**：导出了 `adaptive_curriculum` 模块中的关键函数，使其能在配置文件中通过 `mdp.adaptive_terrain_levels` 引用。

**`unitree_rl_lab/tasks/locomotion/robots/g1/29dof/stair_single_blind_cfg.py`**
*   **修改**：
    ```python
    # [升级] 使用自适应课程学习（自动检测阶段并调整参数）
    terrain_levels = CurrTerm(func=mdp.adaptive_terrain_levels)
    ```
*   **说明**：将原有的 `terrain_levels_survival` 替换为自适应函数。

## 5. 验证与测试

已对代码进行以下层面的验证：

1.  **语法检查**：所有修改过的 Python 文件均通过编译检查。
2.  **逻辑验证**：
    *   确认 Isaac Lab 的 `RewardManager` 和 `TerminationManager` 支持运行时修改参数引用。
    *   确认 RSL-RL 的 `OnPolicyRunner` 支持运行时修改 `alg.learning_rate` 等属性。
    *   确认 `adaptive_terrain_levels` 函数正确处理了 `env_ids` 为空和类型转换的边界情况。

## 6. 使用说明

要启动带有自适应参数调整的训练，请运行：

```bash
python scripts/rsl_rl/train_adaptive.py --task=Unitree-G1-29Dof-Stair-Blind-v0
```

**预期行为：**
*   控制台会显示 `[Adaptive Training] 自适应训练模式已启用`。
*   训练过程中，当阶段发生变化时，会打印详细的 `[Adaptive Training] 阶段切换!` 日志，列出所有发生变化的参数值。
