# 自适应训练使用指南

本指南说明如何使用新开发的自适应训练系统对 Unitree G1 机器人进行盲爬楼梯任务的训练。

## 1. 启动命令

**务必使用新的 `train_adaptive.py` 脚本启动训练：**

```bash
# Windows (PowerShell) - 注意先激活 conda 环境
conda activate isaacenv
python scripts/rsl_rl/train_adaptive.py --task=Unitree-G1-29dof-Stair-Blind --num_envs=4096 --headless
```

> ⚠️ **注意**：Task ID 区分大小写！是 `29dof`（小写 d），不是 `29Dof`。

*   `--task`: 指定任务 ID，对应 `stair_single_blind_cfg.py` 配置。正确的 ID 是 `Unitree-G1-29dof-Stair-Blind`（小写 dof）。
*   `--num_envs`: 并行环境数量，推荐 4096 以获得稳定的梯度估计。
*   `--headless`: 无头模式运行（不显示 GUI），训练速度更快。

**可选参数：**

*   `--video`: 录制训练视频（保存在日志目录下的 `videos` 文件夹）。
*   `--ppo_update_interval`: PPO 参数检查间隔（默认 100 迭代），如需更频繁检查可设为 50。

## 2. 训练监控

### 2.1 控制台输出

训练开始时，你会看到：
```
======================================================================
[Adaptive Training] 自适应训练模式已启用
======================================================================
```

当训练阶段发生变化时（例如从“初始探索期”进入“站立稳定期”），控制台会打印详细的切换日志：

```
======================================================================
[Adaptive Training] 阶段切换!
----------------------------------------------------------------------
  上一阶段: Stage 0 (初始探索期)
  新 阶 段: Stage 1 (站立稳定期)
----------------------------------------------------------------------
  触发指标:
    - Mean Episode Length: 105.3 steps
    - Mean Terrain Level:  0.50
----------------------------------------------------------------------
...
```

### 2.2 Tensorboard

启动 Tensorboard 查看训练曲线：

```bash
tensorboard --logdir=logs/rsl_rl
```

**重点关注指标：**

*   `Episode/mean_episode_length`: 是否随阶段提升而稳步增长。
*   `Episode/mean_terrain_level`: 是否在 Stage 3 后开始显著上升。
*   `Loss/learning_rate`: 是否按照预设的自适应计划逐步降低（1e-3 -> 1e-4）。
*   `Loss/entropy_coef`: 是否随阶段降低。

## 3. 常见问题排查

**Q: 为什么训练很久还在 Stage 0？**
A: Stage 0 的切换条件是 `mean_episode_length >= 100`。如果机器人一直无法学会站立（存活超过 2 秒），请检查物理仿真参数或初始姿态配置。

**Q: 为什么阶段频繁切换？**
A: 系统内置了 5 次稳定计数和 5000 步最小停留时间来防止频繁切换。如果仍然发生，可能是因为训练极度不稳定。

**Q: 如何恢复中断的训练？**
A: 使用标准的 `--resume` 参数：
```bash
python scripts/rsl_rl/train_adaptive.py --task=Unitree-G1-29Dof-Stair-Blind --resume --load_run=2024-XX-XX_XX-XX-XX
```
注意：恢复训练时，自适应状态会被重置，系统会根据当前的指标重新检测阶段。这是符合预期的行为。
